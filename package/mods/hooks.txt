# Translation-time hooks (docs/hooks.md): one `ADDRESS name  # note` per line. An address is the entry of a guest function (the
# translated function calls the hook on entry; the callback can read and change the registers and the guest's memory).
# `in:ADDRESS name` hooks the function containing that address. Re-run `mh3u-tools translate` after changing this list (the launcher
# does it when the list changes). These are the hooks the launcher's Cheats and Mods sections use (mh3u-rt/src/cheats.rs, combat.rs).

# Zenny (the "more zenny" cheat). r3 is the save, r4 the signed change, r5 = &money.
0x0219c720 money_add          # r4 = signed change in zenny (-200 craft fee, -50 meal, -310 quest fee, +310 refund), r5 = &money

# Items (the "infinite items" cheat): the function that puts an item in the pouch or takes it out; a count of -1 is an item used.
in:0x0219b080 item_to_pouch      # f_0219aeac(save, item, count): count -1 = an item used (run 39, twice, from lr 0x285edac, f_0285ecd4)

# Combat (the life bars, the damage meter and the one hit kill / infinite sharpness cheats).
0x02129ef4 hit_resolve           # f_02129ef4: resolves ONE hit; r5 = the hit record: byte +6 = attacker kind (0 hunter, 1 monster), float +0x44 = base damage
0x0259fc98 monster_init           # f_0259fc98(monster, ..): sets a monster's life at spawn (uEnemy::initMaxHp); r3 = the monster, whose state *(r3+0x1be0) holds hp_vital (+0x8b8) and max_hp_vital (+0x8bc). The life bars and the damage meter follow the monsters from here
0x0285f530 sharp_change          # f_0285f530(hunter, change, flag): adds `change` to the weapon's sharpness (negative = it wears)
